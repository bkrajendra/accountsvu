3. Typography
- Primary: SF Pro Display and SF Pro Text.
- Fallback: Inter.
- Headings: Semibold.
- Body: Regular.
- Financial figures: Tabular numerals.
4. Application design direction
I recommend keeping the same design language throughout:
- Sidebar navigation with simple line icons.
- Clean financial dashboard.
- Rounded 10–14px input controls.
- Subtle shadows and borders.
- Blue primary actions.
- Restrained animations.
- Light and dark themes.
